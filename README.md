# API Automation Framework

A production-inspired API automation framework built using Java, Rest Assured, TestNG, and Maven. The project demonstrates industry best practices for designing scalable, maintainable, and reusable backend API automation frameworks.

## Features

- REST API automation with Rest Assured
- Modular framework architecture
- Reusable API client
- POJO-based request and response models
- Configuration management
- Centralized assertions
- Request & Response logging
- JSON Schema validation
- Parallel execution with TestNG
- Allure reporting
- GitHub Actions CI/CD
- Docker support (planned)

## Tech Stack

- Java 21
- Rest Assured
- TestNG
- Maven
- Jackson
- Log4j2
- Allure Reports
- GitHub Actions
- Docker
